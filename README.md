# Pratik Kumar Portfolio

Static portfolio website built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Publish with GitHub Pages

This repository includes a GitHub Actions workflow that deploys the site to GitHub Pages whenever changes are pushed to the `main` branch. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

The site uses relative asset and page links, so it works both at a user site URL and a project site URL.
